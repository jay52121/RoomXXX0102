# 03｜客厅家具遮挡：失去检测不是离开客厅

## 一、明确保留原有工程经验

用户实测认为“人和门底边的位置关系”比较可靠。本版保留并加强这一基准，不用人体点云替代全部空间几何。

典型误判链是：人的腿被沙发挡住 → YOLO 框缩为上半身 → 框底突然向上 → 将框底误当脚 → 跨过画面上的门底边 → 错把客厅人转移到房间。一个人的衣服在某个门框窗口内可见，也可能只是该人站在门前客厅中，而不是已经在门后。

因此，**人体归属、地面位置、遮挡原因、空间迁移是四个不同问题。**

## 二、地面位置必须有来源和不确定性

源码中的原始 `landingPoint` 允许置信度大于 0.00 的脚踝参与估计；历史 Presence 部分路径还使用该值。本版不改旧版本结果，而是在 V3 建立独立地面估计：

| 来源 | 处理 |
|---|---|
| 可信双脚且位置合理 | 强观测，可以参与门线主判定 |
| 只有一只可信脚 | 弱证据，不能独自完成跨越 |
| 无脚但此前有完整身高、框高度稳定、下肢仍可信 | 受约束的框底估计 |
| 截断半身框、框高异常、ROI 底边截断 | 不生成可靠地面点 |
| 短时光流延续 | 弱预测，不伪装成实测，不用于普通“两帧脚点跨越” |
| 视觉跟踪失效 | 保留最后可靠历史；不是继续画预测脚点当真值 |

光流对旧落点的延续最多约 450ms，并不断扩大不确定性。人体各部分存在非刚性运动，因此此延续只能辅助严格门槛接触场景；不能因为肩膀向右动了，就断言隐藏的脚必定向右走了同样距离。

## 三、四个时间/检测状态必须分开

1. 本帧没有执行 YOLO：没有新的检测信息。
2. YOLO 执行失败：本帧感知故障。
3. YOLO 成功，但只推理了另一个 ROI：该人没有被重新检查。
4. YOLO 成功且检测范围覆盖该人，却没有检出：才是有范围限定的掉检证据。

`PortalFrameHub.PoseMetadata` 明确携带成功状态、ROI 和源帧时间。回放采样在 YOLO 忙碌丢帧之前复制灰度图，不再拿推理结束时的播放器时间冒充原帧时间。

关键区别：光流能够补处理被 YOLO 背压跳过的中间采样帧，但当前回放源仍约每 100ms 取图；本版没有假称增加到 30fps，也不是视频原生逐帧离线解码。处理按源帧顺序进行，晚到的 YOLO 结果不重新锚定到未来图像。实际显示延迟仍可能受推理影响。

## 四、具体遮挡策略

**远离所有门的遮挡**：保持客厅人数，对象标为“客厅遮挡”。不启动“最近房间”猜测，不在超时后将人删除。

**接近门但尚未接触门槛**：即使上半身和门框重叠、特征大量失效，也不能推断进门。可靠地面没有到达严格接触区，遮挡路径不提交事件。

**遮挡恰好发生在门口**：需要近期足底接近、有限门线接触、排他门框视觉证据、成熟点的背景恢复等联合条件；详见 01。第二候选门有同等解释时待定。

**客厅人经过 90° 门口转角**：除了门线带符号距离，还检查完整客厅多边形内外。沿凹多边形边界行走时，跨了某条门线的无限延长线并不等于离开客厅。

**靠门休息或站住不动**：已接纳的人不因静止而被注销。是否允许新人准入与是否保持已知人，是两个不同阶段。

**其他人造成遮挡**：重叠像素不作为该人的终止票，身份重叠时冻结迁移。多人完全交叉可能保持不确定，而非强制交换 ID。

## 五、为什么背景恢复也不能单独作为答案

固定摄像头有助于维护背景，但背景差分会受光照、阴影、门扇、电视画面和反射影响。它只能作为附加验证，不等于人体分割。

本版在人体候选和活动点云区域外积累背景。当旧人体纹理跟踪失败时，检查其最后可靠位置是否恢复到此前稳定背景。只有背景已经建立的局部才允许提供证据。

即便真的恢复背景，也可能是人在沙发后躲下去了。所以背景证据永远需要门槛接触约束和门竞争约束。程序没有实现“背景恢复→房间人数+1”的捷径。

## 六、帧跳跃、镜头变化与算法切换

- 重复帧不能使两帧确认器增长，也不能使遮挡计时凭空前进。
- 时间倒退、换源、重新开始回放：新的源世代，丢弃旧世代迟到结果，重新初始化账本与可选初值。
- 大时间间隔：清除短时轨迹和跨门候选，但不把跨缺口的运动猜作真实穿门。已知人数保留，位置范围扩大。
- 全局曝光变化：停止该帧事件判定。
- 背景出现一致整体位移：认为相机可能移动，冻结事件，提示检查标定和重置。
- 切换 Legacy / V2 / V3：清理旧图像缓存、光流本地资源和调试图层，防止旧状态污染新算法。

向前大跨度快进跳过真实事件后，算法不能保证全屋人数准确；应从已知起点顺序回放。对视频 seek 的处理不能代替没有观察到的事实。

## 七、如何看调试画面

青色粗线是真实使用的有限门底边。青色实心小点表示强地面观测，空心点表示短时预测。绿色点和短尾迹表示通过质量检查的人体特征；紫色终止标记表示得到额外背景恢复支持的丢失点，不是“人消失的真实像素真值”。

人体附近文字说明“候选暂不计数”“客厅遮挡保留人数”“跨门待确认”“门来源存疑”“底边跨越确认”等。人数面板显示初值是否已知、提交人数和已知对象的不确定范围。旧 YOLO 骨架和框仍可见，但不会把旧 V2 大框作为 V3 的判断依据。

应特别检查：腿被沙发遮住时，青色实测脚点是否停止，而不是跳到上半身框底；客厅提交人数是否保持；离开家具后是否接回同一人数对象；两个邻门之间的歧义是否被明确显示。

## 八、剩余风险

这不是精确遮挡物识别系统。没有新增家具分割模型，也没有建立房间三维地图。若家具遮挡与门口穿越在当前机位下生成同样的图像证据，本版只能保守待定，或在极窄的接触条件下作标记为推断的事件；不能承诺消灭全部误判。

局部光流在模糊、纯色衣物、极小人体上会缺乏支持，800 个点的上限不能改变这个物理事实。边界以“少判一次”优于“把一个人永久记进错误房间”为原则，后续由真实视频检验漏报与误报的取舍。
