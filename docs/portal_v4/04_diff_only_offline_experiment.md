# SISP：差分独立判定的第一轮离线实验（2026-10-12）

## 目标、边界

先将“门区差分时序如何确认进出”从既有 `PortalV4Core` 状态机中隔离。**不调用原 V4 事件判定、不读取原事件输出或人物房间状态、不使用强脚点或脚点跨门判定**。只消费已经输出的门区差分摘要（包括 owned 差分像素的深度分位数、面积和帧间运动）、人体在门洞中的整体遮挡/轮廓相对位置、门激活阶段和归属 Track。账本只阻止没有来源的内部房间退出以及重复统计；真实事件匹配和人工真值只出现在评估函数中。

**重要：这只是独立的“判定层”，还不是完全独立的图像采集链。** 输入 `portals` 来自旧 V4 视觉层；其门激活仍使用下半身/脚点或人体框底部等替代点。轮廓 `bodySide` 由所有可见人体关键点的平均位置得到，可能包含脚部关键点，它不是纯像素差分；离线脚点跨门判据已经移除。下一阶段必须独立设计无需任何脚点的差分采集/门区激活，并使用原录像重新生成视觉证据。JSON 不含原视频像素，不可凭空补算。

## 观察数据

`SISP_DIFFERENCE_全程判定_工作标注32条_20261012_001104_657.json`（用户文件，未提交仓库），SHA256：`b31f4abb0b56ffa68613f81af33a93c279aebe52300463dea9be6b9f54051fd3`。

- 1431 个已分析判定帧，32 条人工绑定门的进出事件；人工标注时间匹配窗口 ±1000ms，一对一比较方向、门、时间。
- 输入门区诊断共 837 条可用 `ACTIVE/HOLD` 且带所有权 Track 的差分记录。按门区时间合并为 40 段活动：其中 30 段覆盖全部 32 条人工真值（两个连续进入→退出需要拆分），另有 10 段没有人工进出事件。
- 原始 V4 命中 14/32；PR #17 反向脚点修复后的离线移植版 19/32；本实验独立差分原型 **32/32，零未匹配输出**。

### 与算法无关的约束

1. 保留原始门区差分，先按门聚合，不因旧 V4 的房间账本抑制其他门候选。
2. 用连续的轮廓相对门线位移、差分深度分位数变化和吸收/释放趋势综合决定方向；允许深占用期间方向反转。
3. 高比例吸收后消失只有在强前景运动且深度分布改变时才支持进入；原地静止后遮挡不算穿门。
4. 识别候选后才应用每个人/房间的计数约束，防止误报在后续房间间级联。
5. 匹配工具读取真值，但 `infer()`、`classify()` 绝不读取 `groundTruth`、已有 `outputs`、已有人员房间状态和脚点。

## 结果与抗过拟合压力测试

本结果是在**看过并调试过这段录像**后取得的开发集成绩，**不是独立留出数据**：

| 验证方式 | 结果（固定随机种子，20 次） |
| --- | --- |
| 原始数据 | 32/32，零未匹配输出 |
| 删去原算法输出、人物状态及关键点输入（保留地图上下文） | 32/32，零未匹配输出 |
| 整体重编号 Track | 32/32，零未匹配输出 |
| 每帧时间 ±20ms 抖动 | 20/20 次完全正确 |
| 差分面积/深度/人体区域信号 ±2% 随机扰动 | 19/20 次完全正确；平均 31.90/32 |
| 同类信号 ±5% 随机扰动 | 13/20 次完全正确；平均 30.85/32 |
| 随机丢失 3% 判定帧 | 10/20 次完全正确；平均 30.60/32 |
| 随机丢失 10% 判定帧 | 1/20 次完全正确；平均 26.90/32 |
| 随机丢失 20% 判定帧 | 0/20 次完全正确；平均 23.55/32 |
| 合成的门区原地静止随后遮挡（无空间迁移） | 零事件 |

上述噪声测试只扰动**已有视觉摘要**，不能代替对原始视频像素做光照、遮挡和采样扰动。压力测试表明当前模型对掉帧仍然脆弱，**不能声称算法“泛化准确率100%”**。

### 在线延迟限制

此次原型在完整门区活动结束后回顾判定，并把输出时间标为估计的实际穿门时间。`episode.end - event.time` 的中位数约 **1415ms**，最大 **2945ms**。回放匹配的 ±1000ms 是回填的事件时间，不代表实时消息一定在穿门后 1 秒内出现。Android 版应增加独立的首次确认时间、输出到达时间、回填事件时间三项测量。

## 复现

本模块只依赖 Python 3.10+ 标准库，测试使用 pytest。将录像 JSON 放在本地任意路径：

```bash
python3 tools/diff_only_proto.py /path/to/SISP_DIFFERENCE_20261012.json
python3 tools/diff_only_stress.py /path/to/SISP_DIFFERENCE_20261012.json --rounds 20
SISP_DIFF_REPLAY=/path/to/SISP_DIFFERENCE_20261012.json python3 -m pytest -q tools/test_diff_only_proto.py
```

测试脚本可在缺少录像时运行 7 个合成单测并跳过完整录像回放。录制原数据 5.9MB，不应作为提交条件或嵌入硬编码门号/时间。

## 下一步与上线门槛

1. **移除采集阶段的脚点依赖**：建立只由门口人体轮廓/运动像素触发的差分 ROI 采样通路，保留未激活门的短期灰度预录；支持门底边两侧的差分时序，不只量化门后单侧深度。
2. 将离线原型改造成具备有界等待时间和低漏帧敏感度的流式算法；原始录像和未见录像应分别报告事件准确率、误报率和实际延迟。
3. 用不同时间、人物、服装、速度、逆光、多人遮挡的新录像作为完全独立验证；冻结参数后再评估。通过之前本原型**不替换生产 V4**，不合并实验 PR。
