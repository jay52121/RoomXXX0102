# V5.4：以门区法向真实运动为主证据的穿门状态估计

## 为什么不是 V5.3.1

此前 V5.0–V5.3 的离线回放主要复用了已经计算出的差分面积、姿态中心、覆盖率和历史持续时间。V5.2 Android 相同录像的最新一次实际严格匹配仅16/32；在其他采样可做到32/32的判据，无法抵抗背景差分像素数量级变化（最多约54倍）。再叠加阈值不足以说明真正穿门。

V5.4 不是复制 V5.3 的 classify/propose，而是从零实现独立的 `DiffV54Core` 有限状态机，区分 WATCH、APPROACH_IN/OUT、TRANSIT_IN/OUT、OCCLUDED、RETREAT、CONFIRMED。每一状态转移只使用截至当前帧的证据，不知道人工标注时间，不在输出时回填旧帧时间。

## 采集层：继续省算力

- **保持 V5.2 的人体框与门区重叠触发**，同时处理最多两扇门。没有引入全门持续20fps的高成本差分。
- 仅在 V5.4 已激活的门区追加本项目已存在的局部双向 LK 光流（最多64特征点、受单帧预算控制）。
- LK 的起点为**可见人体轮廓与门区相交的掩膜**，避免依赖由背景参考导致变化几十倍的原差分掩膜。LK 当前图像与上一图像之间的真实位移，投影到 `FlowGate.side()`：负值意味着朝房间，正值朝客厅。该方向来自标定几何而不是脚点。
- 门区原有前景差分仍作为人体归属和遮挡辅证，差分**绝对像素数不再决定穿门确认**。
- 逐门记录 `opticalNormalDelta` 与 `opticalTrackedPoints`，并扩展事件诊断导出的 portalColumns，便于把“光流证据缺失”与“状态机拒绝”分开审查。

## 判定：可纠错且尊重物理不确定性

- 以每帧 LK 法向移动增量和较弱的姿态侧向移动构成运动轨迹；用采样时间间隔限制积分，不再因为固定帧数少一帧就直接失败。
- 对观察噪声维护有界的自适应底噪；方向变化若导致尚未完成的进门被撤销，进入 RETREAT，本段不会再被反向识别为 EXIT。
- 只在可靠的门区法向光流连续出现，且**跨门运动已经形成 + 人体门区占用的完成/清空证据**时允许发事件；确认延迟使用配置 `confirmMs`（默认120ms），对外事件时间等于真实发布帧。
- 人数账本只在发布时更新，不对新视觉事件进行“当前人数=0就禁止 EXIT”之类硬否决。旧计数错误可以由新、独立的强视觉证据纠正。
- 视觉不健康、轨迹反转、采样倒序不能产生虚假穿门。光流不可靠时宁可保留不确定状态，不通过单纯人体框/差分面积猜测。

## 诚实的验证范围

本地纯 Kotlin 状态机已用合成运动进行多采样间隔（75/90/100/120/150ms）、约10%–25%漏帧、人体位置微扰、差分像素幅度0.15×到20× 的确定性/抗扰动测试，ENTER/EXIT方向一致。独立 RETREAT 测试修复了“靠近门又退回被识别成退出”的缺陷。

**四份旧 Android JSON/固定回放都没有保存 `opticalNormalDelta`，不能用于评价这一新版感知链路准确率。** V5.4 禁止用缺失的 LK 证据假造事件，所以这些缺少新字段的旧输入得到0/32，而不是新算法真实准确率0%或100%。它们用于确认“缺少光流时不会乱报”和“不读取人工答案”，不能充当 V5.4 整链路验收结果。

## 真机回放必须测的指标

1. 实际光流正常帧比例、每扇门每次事件附近是否连续至少两帧可靠光流、LK光流有效点数、门区额外处理开销（P50/P90/P99）。
2. 人工T下按门/方向、一对一 [-100,+1000]ms 真实输出帧匹配；其中 +500ms 的数量单列；不能借回填时间作弊。
3. 是否误报站门口、接近后折返、邻门经过、Track交接；以及全程房间人数是否一致。
4. 对同一视频的新旧采样分别测真实输出，不能只给一次离线32/32；对独立新视频留盲测集。
5. 如果 LK 缺失严重，不要简单放宽时间或像素阈值，先诊断是不是纹理点不够或局部预算耗尽。

V5.4 作为**独立实验选项**，旧 V4/V5.0/V5.1/V5.2/V5.3 完全保留供正常切回；暂不设默认。通过CI并直接合并到 `9月新房间判定算法` 只意味着可供真机采集新光流证据，**不是已验证真实准确率**。
