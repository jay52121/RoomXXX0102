# V5.4 真机因果回放第二轮修复（2026-10-13）

## 本次修复范围

基于已经合并的 PR #23 工作分支，对 V5.4 **判定核心**进行局部修复，不改变 V5.2/V5.3 的采集启动策略、不添加全门 20fps 差分、不改变任何旧版 V5.3 的判定行为。V5.4 仍是验证版，并非正式默认算法。

主要问题是：V5.4 在本段真机光流记录中，虽然检测到了法向光流和人体框位移，却将 `RETREAT` 当成整个跟踪期的永久否决；小幅度光流会完全压制更大的同向人体位移；进入时又将 `absorption >= 0.975` 直接当作穿门完成。

**改动：**
1. **折返隔离与重新开启。** `RETREAT` 只取消当前尝试；后续新的向内动作，必须同时得到至少两次新光流、持续内移、门区覆盖，以及最小独立运动间隔才能恢复判断。若出现明确退出观察窗口后的重新进入，也可解除本次冻结。原先接近后直接退回仍禁止当成跨门。
2. **双传感证据联合估计。** 同一方向的局部 LK 与人体框位置变化联合计算，防止幅度极小但“可靠”的 LK 一票否决真实的较大位移。冲突证据仍保守处理。
3. **进入完成不等于覆盖饱和。** 记录首次饱和时刻/人体侧向基准；需要饱和后进一步向内移动、充分的先前物理进展，或经遮挡后可信地重新出现，才可产生候选。不会仅因 100% 覆盖就立即提交。
4. **退出不必等前景完全离开画面。** 对从较深/高占用门区开始、已有足够连续 LK 与人体方向一致向外位移的真实退出，允许比大范围遮挡消退更早确认；其他退出继续使用峰值清空判据。
5. **保留真正响应时间。** `Crossing.timeMs` 始终等于算法实际输出所在视频分析帧的时间戳；即使后来确认真实穿门也不回填事件历史时间。

## 仍然存在的硬限制

- 新核心使用 `bodySide`（二维投影）、光流与遮挡行为作为物理运动代理；**二维门区饱和与内移不能严格证明人体的三维真实门槛跨越**。还缺乏完整原视频、可验证的三维门槛/前后分区证据。
- 可靠 LK 仅约 366/1161（31.5%）；次卧 4/75、书房 31/196。只有这份已录制的光流测量无法补出原先没有采集的方向信息，因此不少门仍然漏判。
- 下一步若要大幅提高最终准确率，应优先改善窄门的局部流与身体跨越前后空间标定，而不是降低现有阈值；并且必须先用有标注的新视频独立检验。
- **V5.3 真机严格 24/32，仍优于 V5.4 本次 11/32。** V5.3 保持可以随时切回。编译与本次回放通过不代表建议以 V5.4 进行正式人数统计。
