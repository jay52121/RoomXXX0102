# Portal V4：可调整参数与调试顺序

## 操作原则

先在“房间算法”选择 A/B/C，再点“V4 A/B/C 参数调整”。各方案独立保存，修改后返回画面，从同一个视频开头重播。初始人数也必须一致，不能将中途人数当成开场初值。

不要一次修改所有参数。先看失败在“采帧 → 前景 → 人体准入 → 门接触 → 跨越 → 人数接续”的哪一步，再调整该步。低阈值可能提高召回，也可能制造长期人数错误。

## 共用参数（均已接入设置）

| 参数 | 默认 | 允许范围 | 调整意义与代价 |
| --- | --- | --- | --- |
| 采样周期 ms | 50 | 33–200 | 越小越频繁；线程忙时仍直接拒绝，不制造队列 |
| 采样图长边 | A/C 1280；B 1920 | 640–2560 | 控制回放 Bitmap 读回大小；小 ROI、手部细节建议提高，不改变模型输入 640 |
| 门口视觉长边 | A/C 480；B 640 | 320–960 | 门太窄、有效特征太少时先提高它，再考虑增加点数 |
| 视觉最大间隔 ms | 300 | 150–500 | 超过即中断视觉连续性，不把跨掉的一段推定为进门；不能无限调大掩盖慢帧 |
| 亮度差阈值 | 18 | 8–60 | 越低越敏感；暗衣服与背景相似可适度降低，噪声/曝光多则提高 |
| 空门背景预热 ms | 600 | 300–5000 | 需要门口无检测人体且稳定；不是等待时间一过就必定拥有空背景 |
| 背景恢复确认 ms | 200 | 120–1000 | 降低可更快确认，增加可抑制短暂空窗；不是 YOLO 消失超时 |
| 允许残余前景比例 | 0.08 | 0.02–0.20 | 相对曾获得的有效人体前景峰值；越大越容易认为窗口已恢复背景 |
| 门槛接触带（人高比例） | 0.10 | 0.05–0.20 | 在图像尺度中容许接触区间，内部另有上限和脚点不确定度限制 |
| 可见跨门确认 ms | 120 | 100–600 | 仍要求至少两个独立时刻；变大可减少门口来回抖动，变小可能增加误报 |
| 真人准入最小位移 | 0.012 | 0.005–0.04 | 在宽高比修正的归一化图像坐标中计算；不是米数 |
| 遮挡证据最长保留 ms | 1400 | 600–2500 | 长时间没有可靠锚点后不再用旧证据强行迁移 |

“采样图长边”作用于 V4 正常播放回放；暂停逐帧与 CameraX 仍沿用各自既有采集方式。三版视觉后处理分辨率均受“门口视觉长边”控制。

## A：差分优先怎么调

先看门内黄色前景是否真的覆盖人体：
- 完全没有前景：检查空门预热、曝光、人物与背景亮度差，再适度降低亮度差阈值。
- 全是噪声：先看是否灯光/摄像机改变，再提高亮度阈值或降低分辨率，不先放宽穿门条件。
- 人还站着却被认为清空：把残余比例降低、恢复确认时间增加；同时检查背景是否在人存在时被错误初始化。
- 已到门槛、真实消失却保持待定：先看是否仍有门扇或其他物体的前景。如果有，保守不确认是设计选择；放宽残余比例可能带来路过误报。

原始帧差为零只表示不再变化。A 同时看固定背景，不会用“停止移动”直接替代消失。

## B：光流优先怎么调

| 参数 | 默认 | 范围 | 意义 |
| --- | --- | --- | --- |
| 单门特征上限 | 192 | 64–384 | 同时最多两门；是上限，不保证纹理不足时能得到这么多有效点 |
| 正反向误差容限（像素） | 1.5 | 0.5–3.0 | 过小会丢掉很多点；过大易允许漂移，单位为视觉工作图像像素 |
| 金字塔最大层号 | 2 | 1–3 | 层号 2 代表含原图的 3 个尺度；更大可处理较大位移，但更慢 |
| 可选光流预算 ms | 30 | 10–60 | 已超预算就不启动后续门/补点/逆向查询；不能中断正在运行的原生 LK |

优先顺序：先检查采样间隔和图像清晰度 → 再检查门口分辨率和空间覆盖 → 再调整点数与容差。增加点数不会让光滑衣服凭空长出纹理。目标是多个身体部位上的可靠点，不是面板数字最大。

B 仍保留每次参与可靠性判断的正反向校验。停止、遮挡或光流失败不直接形成进门票。若时间预算经常耗尽，先把 192 点降到 128，再看 640 长边是否可降到 480。提高预算用于能承受性能下降的对照，不能以增加积压换“精度”。

B 的逆向来源查询最多三对历史图、64 点，与前向共享可选预算。没有足够连续历史时不猜。第一次 Pose 出现较晚的门，A/C 与 B 可能真实表现不同。

## C：MOG2 怎么调

| 参数 | 默认 | 范围 | 意义 |
| --- | --- | --- | --- |
| 方差阈值 | 16 | 8–64 | 越低越容易判前景；过高会吞掉低对比人体 |
| 无人物时背景学习率 | 0.025 | 0.002–0.08 | 越高适应背景更快；事件与人物存在时强制冻结，不允许把停住的人快速学成背景 |

C 对 MOG2 阴影标签作剔除，但“深色衣服被当阴影”仍需实际观察，不保证开阴影检测就没有误伤。由于消失提交还检查固定背景恢复，MOG2 单独吞掉人体不应直接触发进房。

## 不作为自由参数暴露的安全条件

这些不应靠“调得很宽”绕开：
1. 未接纳人体不能仅凭门口运动创造人口。
2. 门线必须是有限段，不能用无限延长线假跨越。
3. 同一人体覆盖两个门，不能仅以第一次接触永久锁门。
4. 多人争夺同一门的视觉归属，不能当成独占证据。
5. 丢帧、推理失败、ROI 未覆盖，不等于人消失。
6. 光流普通失效不等于人体消失。
7. 背景未知时，不以“恢复背景”确认事件。
8. 内部房间迁移不能凭空增加全屋人口。

## 最小调试步骤

先用一段包含“空客厅 → 人出现 → 普通进门 → 出门 → 门口经过 → 家具遮挡”的视频。三版保持相同初值，各从头运行。

重点记录错误发生的时间、门名、方法、面板状态与帧率，不要求先搭庞大标注平台。调整一个参数后复跑该错误片段，同时检查原先正确的路过/停止片段是否变成误报。

现有合成单元测试验证条件与守恒，不代表已经覆盖真实光照、门扇、纹理和所有手机调度。
