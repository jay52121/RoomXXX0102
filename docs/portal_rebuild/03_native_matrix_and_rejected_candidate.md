# 步骤3：原生交叉回放与一个必须否决的高分候选

## E07：同一套 Kotlin 二进制交换输入

源码取自审计基线。一次编译 DiffV5Core、DiffV51Core、DiffV52Core、DiffV53Core、DiffV54Core，再逐帧喂入不同实际录制的测量。没有把 groundTruth、原 outputs 或判定后 diagnostics 输入分类器。配对仍为真正响应帧[-100,+1000]ms。

单元格格式：严格命中/32，未匹配输出数，500ms内命中数。

|输入来源|V5.1核心|V5.2核心|V5.3核心|当前V5.4核心|
|---|---|---|---|---|
|V4.3录制|32,0,21|32,0,21|25,3,18|BLOCKED：无真实LK|
|V5.0录制|32,0,19|32,0,19|21,2,15|BLOCKED：无真实LK|
|V5.1录制|27,1,18|32,0,21|28,2,18|BLOCKED：无真实LK|

说明：V5.0核心在所有输入上按真实发表帧计分均为0，因为其整段结束后才提交。V4.3和V5.4向差分核心的输入是由记录的portal测量字段机械映射；V4.3映射保留821条有owned掩膜的观测，不等于历史837条压缩fixture，所以该列只作为声明了适配规则的诊断实验。V5.0/1/2/3的signals则原样逐帧输入。V5.4当前核心包含PR #24，11/32不是原始运行时的4/32。

## E08：只按录制划分，几乎可以得到满分——但它是危险的

构建了一个离线候选：以当前与过去100–1400ms的门区占用分布、形状归一化网格、覆盖率、运动、可见性形成253维因果特征；不输入绝对视频时间、门ID、轨迹ID或旧算法结果。HistGradientBoosting，固定80轮、15叶、学习率0.08、L2=5、最小叶20、随机种子7。输出门槛固定0.5，同门同人同方向900ms防重复。所有参数在下列结果出来前固定，之后没有再调。

人工标签仅用于离线监督：GT之后0–400ms的同门帧分别标ENTER/EXIT，其余为非事件。推理只看现在和过去。

### 划分A：留一份录制，其余五份训练

按输入顺序V5.1、V5.2、V5.3、V5.4、V5.0、V4.3：
- 严格命中：30、31、32、32、30、30（合计185/192，96.35%）。
- 六份未匹配输出均0；命中均在500ms内。

乍看远高于旧核心。但训练集中存在同一视频同一次物理动作的其他采样，模型能识别重复的动作特征，不能当成独立验证。

### 划分B：把同一次物理路线循环在全部录制中一起留出

按预定义视频三段0–54s、54–104s、104s以后，整段在六份录制中共同留出，避免训练看过被测物理动作。仍用同一算法、参数与输出门槛。
- 严格命中：10、12、9、11、8、9（合计59/192，30.73%）。
- 未匹配输出：4、1、5、4、4、2。

**结论：否决这个候选作为上线方案，不把96%甚至个别32/32写成成功。** 本实验只证明这个候选和这种“留一份录制”的验证方法存在严重重复事件泄漏，不证明所有学习模型都不可行。三段本身还存在路线/场景分布差异，仍非新视频盲测。

## 设计决策

不再把六次录制当作六组独立答案。后续训练、参数选择、验证都需要按原视频/物理事件分组；重复录制只用于检验采样稳定性。状态模型必须具有明确可观测的源侧→边界→目标侧证据，不能仅凭这段视频的特征签名分类。
