# 步骤2：用可复现证据检验原模型，而不是再调标注阈值

代码基线 `cf2089c967f571a5a0cc0f6f9f784c802c5fbf32`。核心源码经 GitHub Actions 原样打包到本地，用 kotlinc 编译；没有用 Python 仿真替代本节原生结果。

## E01：同一无噪声动作，采样越密反而完全不报

实验：人体位置 `side(t)=-0.10-0.03*t/1000`，占用 `min(1,0.80+0.00015*t)`；法向光流等于两次取样之间的真实位移，24个支持点。仅改变采样间隔。

|间隔|原生 V5.4 输出|最终状态|
|---:|---|---|
|50ms|无事件|WATCH，travel=0|
|75ms|ENTER@1800ms|CONFIRMED|
|90ms|ENTER@1800ms|CONFIRMED|
|100ms|ENTER@1800ms|CONFIRMED|
|150ms|ENTER@1800ms|CONFIRMED|

复现代码：`research/portal_rebuild/TemporalCounterexample.kt`，与基线 `DiffV54Core.kt` 一起编译运行。

根因：`epsilon=max(.0018,noise*.70)` 比较的是**每帧位移**，不是速度或有单位的统计显著性。同一速度在50ms只移动0.0015，被当成静止；100ms移动0.003则累加。`.90/.10`噪声更新也按帧而非真实时间衰减。该反例不证明真实穿门时刻，但严格证明：即使完全没有环境噪声，模型也不具备宣称的采样不变性。

## E02：传感器调度状态不等于人是否被遮挡

在原始V5.4真实记录中，371条HOLD记录有216条（58.2%）仍在detections中观察到同一owner，并且bodySide非空。V5.3对应402条HOLD中232条仍可见。

`DiffV54RoomAlgorithm` 将 `phase==ACTIVE` 映射到 Measurement.active；核心将 `!active` 映射为OCCLUDED。这样把调度HOLD、人体离开候选门、预算/门间竞争和真正视觉遮挡混为一谈。不能靠调低消失等待时间补救。新数据契约必须分别记录 sensorProcessed、ownerVisible、visibilityReason、ownershipConfidence。

## E03：人体位置锚点本身在跳变

原V5.4儿童房：50362ms有效关键点9个，bodySide=-0.15708；50444ms变成11个（两个膝部点参与），bodySide=-0.13017；50535ms又回到9个，bodySide=-0.16007。`portalBodyEvidence` 对“当前所有可见关键点”求平均，使不同解剖点集合被当成同一个运动点。这里只能证实锚点定义不一致；身体框也发生变化，不能把全部位移归咎于某一个点。重建必须用固定语义的肩/髋对应点与置信度，不得在不同集合的均值间直接求速度。

## E04：光流跳过时，纹理点与参考图可能不同步（源码级风险）

GateEventLk 在预算不足时提前return，不更新其dot坐标和time；GateEventVisionV2仍会在processActive末尾把当前gray复制为previous。下一次LK恢复时，可能用旧dots配新的previous图。当前记录不含每个dot所属frame ID，所以不能统计该风险实际影响了哪些GT，但实现层缺少保证。这不是通过固定输入才能解决的问题，必须在接口上原子绑定点、图像与时间。

## E05：可能最关键的穿越证据被筛掉（源码级风险）

GateEventLk只在 `gate.containsBody(after)` 为真时才保留光流样本，离开门区的点被直接删除。V5.4随后只统计live样本均值，不能据此恢复被删除的边界穿越/终止位置。重建需要保留source、terminal destination、离开边界、遮挡/丢失的不同原因，而不是把“已离开”当作“没观测”。尚不能仅凭旧汇总JSON量化其召回影响。

## E06：图像法线不等于已标定的三维门槛法线

重新读取用户的《roomxxxmp4空间标定说明.md》：非主空间四边形是门口和门后通道的二维透视过渡区；原说明明确不能确定真实深度、精确三维朝向和相机内外参（2.3、4节）。它不是完整房间，也没有声明它是竖直物理门面的四角。

因此，将 `FlowGate.side()` 的图像带符号距离、纹理位移和100%门区覆盖组合后称为“物理完成”，超过了标定所支持的含义。光流可作为可见运动的证据，但不能单独提供跨越完成时刻。不能靠把字段改名为physical修复该问题。

## 本节结论

采样依赖、观测语义混淆、锚点不连续、纹理历史失配、边界证据删失以及完成条件未定义，是六类不同问题。不能用更多算力、更多帧、一个新状态名或一组更宽阈值共同掩盖。每一类都需要独立可失败测试，最后仍必须通过六份真人录制和新录像的完整质量门禁。
