# 步骤4：从头重新定义测量、事件与验收

## 1. 保留的东西

保留人体框与Portal重叠时启动局部分析、最多两门并发、原始视频时间、YOLO/Track接口和诊断导出。它们不是当前应推倒的部分。没有引入全门20fps差分，也没有暗中退回脚点跨线判定。

## 2. 原模型缺失的关键变量

过去测量了“运动多少”，却没有定义“距离所需的穿越边界还差多少”；观察起点任意、动作进展从0累计，使同一个人提前进入ROI就可能提前被算成穿门。

新的核心需要的不是另一个经验分数，而是带来源的**源侧观察、边界转移证据、目标侧观察**。标定未知、测量缺失和邻门归属不明，必须保留UNKNOWN。不能把覆盖率1.0、光流为负或观察够久当作目标侧证明。

## 3. 四个相互独立的层

### A. 测量层：不输出穿门结论

每个观测绑定：视频PTS、图片帧ID、前后帧ID、纹理点所属帧、人体实体/跟踪代次、锚点类型、Portal几何版本、是否真正计算过、人物是否可见、遮挡/出界/预算跳过原因、测量方差。

- 点、参考图、时间作为原子包保存；预算跳过后不得旧点配新图。
- 采用固定语义对应点或对应纹理轨迹。关键点集合改变不是人体位移。
- 保留跨ROI边界的终止轨迹和去向，不能删掉离开ROI的点再说没有穿门。
- 局部运动表示为带真实dt的有符号位移和速度；滤波系数按真实时间 `1-exp(-dt/tau)`，不是固定每帧0.1。
- UNKNOWN不是0；HOLD不是OCCLUDED；可靠性低不是“人没动”。

### B. 可证伪的穿越证据提取

现有Portal四边形仅是二维透视过渡区，不能直接充当真实三维门面。保留两条待原片验证的路线，不预先把其中一条宣传成成功：

1. **图像证据路线**：已核对的源侧/目标侧可见区域、门框/遮挡边界和同一人体纹理的时序转移。需要证明路过、走近、门前徘徊不会产生同样的“完成”证据。
2. **几何路线**：从原片中的实际门槛、静态线结构与人体稳定语义特征建立可核对的投影关系；必须明确它是近似还是受标定支持。不得把图像垂线直接叫三维法线，也不默认引入脚点作为唯一完成条件。

旧JSON的空间汇总没有保存被删掉的终止纹理、完整前后帧和实际遮挡边缘，无法从它们重算以上像素证据。这是目前待获取/验证的输入，不是算法设计问题的借口。当前库中找到了空间标定语义说明，尚未取得原始视频文件。

### C. 因果事件内核

同一实体先被可靠观察在源侧，经过边界不确定带，再被可靠观察在目标侧，短时确认后发表。未完成的折返只撤销候选；新源侧→目标侧转移可继续，不锁到整段ACTIVE结束。不设置“一段最多两事件”或跨门950ms绝对禁令。

事件携带 sourceSeenMs、destinationSeenMs、publishedMs。真实跨越一定在前两者之间，若 `publishedMs-sourceSeenMs<=1000ms`，则对该证据的最坏延迟也不超过1秒；不能靠随意回填T获得这个保证。此推断**以源/目标侧测量确实正确为前提**，正是B层必须验证的内容。

低成本重叠观察发生在穿门前；500ms主要留给目标侧证据和约120ms确认。目标时间不等于“等待时间够长即可提交”。队列耗时另用单调时钟记录，视频时间与真实墙钟响应分别验收。

### D. 独立人数账本

账本只消费已发表事件，不反过来否决新的穿越证据。初始人数未知必须仍是未知，保留有符号人数变化；不能每次减到负数就截为0，随后又加1而制造新人数。事件ID确保幂等；纠错以显式记录处理，不偷偷删历史事件或回填时间。

## 4. 已写出的研究内核及其真实边界

`BoundaryTransitionCore.kt` 实现以上C层的最小原型，以及帧配对检查、连续时间速度滤波和独立人数变化账本。它不是完整视觉算法，**没有接入Android算法列表**。

初版1800组测试出现1个失败：150ms采样、10%丢帧、seed72。原因为按400ms空档直接清空源侧历史，重演了“调度空档等于物理状态改变”的错误。修正为身份/锚点/几何变更才清空语义状态，用发表时间减最后明确源侧时间限定可证明延迟，测试数据、种子和验收窗口未放宽。

修正后1800组（6种采样间隔×100种相位/噪声种子×0/3/10%丢帧）均为单次正确方向、零额外输出、[-100,+1000]ms内；最坏延后572ms，其中3组未达500ms目标。额外检查折返后重新穿越、无标定不输出、旧点配新图拒绝、锚点改变、正反位移抵消、未知初始人数保持未知。

**这1800组是已知理想边界测量下的内核测试，不是1800次真人实测，更不是全系统PASS。** 真正的B层视觉提取未由原片验证，因此真人总体状态仍为BLOCKED/FAIL。

## 5. 完成顺序与不可替代的关卡

1. 原始资料/实现/标注语义审计：已完成第一轮，见00–03。
2. 测量契约和内核不变量：研究实现已测试，但不能替代像素验证。
3. 原片上32个事件逐帧核对；证明源侧/目标侧证据何时首次可用，不改标注。
4. 原生像素→测量→内核端到端回放；旧六种采样方式全部复跑，不仅交换旧差分摘要。
5. 按物理事件/独立视频分组留出，禁止将同一次动作的另一次采样放入训练。
6. 量化全部真实复测、扰动最坏值、额外输出、500ms和1秒尾部；任一硬门槛失败均FAIL。
7. 只有全部关卡通过，才替换应用判定核心并按常规工作分支交付。报告/审计工具可以先合并，但不能把它叫作新算法通过。
