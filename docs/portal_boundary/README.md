## 1. 不再重新讨论的需求

| 项目 | 固定要求 |
|---|---|
| 输入场景 | 当前固定机位与原Portal/房间标定；32条人工事件及方向/房门不改 |
| 采集 | 保留人体框与门区重叠触发；通常最多2扇门进行重点像素处理；不采用全部门持续20fps重型差分 |
| 遮挡 | 不把脚点、膝点或框底部穿线重新当作遮挡主方案 |
| 正常事件 | 每个标注恰好对应1个正确房门、正确方向的输出；漏报0、额外输出0 |
| 时间硬约束 | 实际响应所在视频帧与人工T之差在 **[-100,+1000]ms**；不是对称±1秒 |
| 优先目标 | 尽量全部正常事件在T+500ms内；独立给出逐条与总量结果，不偷换成较低命中率下限 |
| 时间记录 | 使用真实发布帧；可以另外记录估计发生时刻，但不能用回填时刻掩盖延迟 |
| 交付 | 通过相应验证的改动合并当前工作分支；不以单独APK代替；保留明确回退点 |
| 泛化 | 同一原视频不同采样不是新动作盲测；不能宣称未知一切场景数学上100% |

500ms是目标、1000ms是硬上限，两者不能混淆。验收器分别输出两个状态，并提供仅可收紧的`--require-target500`，没有降低正确条数的选项。徘徊等复杂情况单列，不能用于放宽这32条正常穿门的要求。

PR#24核心对**已保存的V5.4输入**回放为11/32、额外0、500ms内7；这不是第七份真机全像素测试。修正运动观测后、保持同一V5.4核心的单变量实验为16/32、额外3，依然失败，不能直接上线。

已经证实或必须区分的发现：

- **证实：观测对象不一致。** `portalBodyEvidence()`对“当前可见关节点”取均值，前后成员变化会制造虚假运动。儿童房51.113s附近原均值位移约+59.1像素，同名关节点位移中位数约-0.85像素。不能把此类跳动当作折返。
- **证实：采样单位错误。** 当前核心对同一连续匀速输入，100ms采样有ENTER，50ms采样没有；原因是每帧0.00175位移低于固定0.0018门槛。更密采样不能使真实运动消失。
- **证实：早启动有效但旧判据不适配。** V5.2已让32/32事件在T之前开始门区观察；继续让所有门常开不能解决提前误判。
- **证实：状态生命周期错误。** RETREAT曾连续冻结数秒；账本和跨门定时锁会压制后续新证据。补丁有所改善，未解决完成语义。
- **测量定义：饱和不是完成。** `bodyInsideRatio`是局部裁剪中构造人体掩膜的覆盖比例，不是真实人体穿过三维门平面的证明。关节点绘制的掩膜也不等于精确人体分割。
- **测量定义：法向不是三维深度。** 衣服纹理沿图像门底边法线移动只表示图像运动；头肩像素不在地面单应平面上。不能靠累积一个归一化位移量认定跨门完成。
- **源码风险，尚未逐事件归因：** LK预算跳过后图像前进、纹理点不前进，可能混用不同源帧。必须修正其输入契约；不能提前声称它解释全部漏判。
- **测量定义：网格不是等质量像素。** 8×4导出值是各单元占用率，透视单元容量不同，必须保留真实命中数/容量，不能等权求“前景质量质心”。

## 3. 明确选定的算法

**事件驱动局部人体前景 + 边界锚定的前后侧/遮挡证据 + 连续时间多假设状态估计。**

不采用“把V5.4所有阈值再调一遍”；不要求每次事件都必须有LK；不凭低置信度关節中心替代缺失光流；不使用整个门区活动已经持续多久来证明完成。

### 3.1 基本不变量

1. 只比较同一目标、同名关节或同一纹理轨迹；坐标、支持点和图像源帧必须一致。
2. 位移单位为归一化图像坐标或像素；速度必须除以真实dt；不是世界米制距离。
3. 小位移可以带较大不确定性参与累计，不被固定每帧门槛永远丢掉；测量缺失不等于0运动。
4. 事件需要**与标注语义一致的穿越完成证据**；时长、运动方向、覆盖率只能辅助。
5. 冲突或缺测保留“不确定”，不能造事件赶时限；在这32条中未能及时确定仍应记为失败。
6. 轨迹身份与穿门尝试具有不同生命周期；撤销一个尝试不冻结整个人或整扇门。
7. 人数账本不反向创造、否决视觉证据；未知初始人数不解释为确定0人。

### 3.2 模块与接口

| 模块/建议类名 | 输入 | 输出 | 禁止事项 |
|---|---|---|---|
| 现有门区调度器 | 人体框、Portal、视频帧 | 最多2个活动ROI、源帧序号 | 把ARMED起点当穿门起点 |
| `PortalForegroundObserver` | ROI像素、稳定参考、人体种子、可见性 | 人体前景分量、前后区域命中/容量、遮挡边缘支持、质量标记 | 把骨架绘制掩膜当精确分割；把全ROI背景差分都归给人体 |
| `PortalImageMotion` | 前后同身份同名上身点 | dx/dy、vx/vy、dt、支持数、残差尺度 | 可见点集合均值做差；读取脚/膝/框底部 |
| `PortalTextureMotion` | 源帧一致的纹理点和前后ROI | 匹配点位移、散布、源帧、质量 | 跳过一帧后用旧点配新图；把方向当完成 |
| `PortalBoundaryEvidence` | 固定边界标定、人体前景与可见性时序 | 源侧/边界/目的侧支持与完成证据 | 用100%覆盖或固定路程直接发事件 |
| `PortalTemporalEstimator` | 上述观测及实际dt | 多个尝试假设、候选/撤销/完成证据 | 从录像GT、门编号或全片绝对时间拟合规则 |
| `PortalEventArbiter` | 同身份多门候选、空间归属 | 去重后的正式事件 | 固定950/220ms禁止不同门的合法连续事件 |
| `PortalOccupancyLedger` | 正式事件、已知/未知初始计数 | 人数及不确定性 | 先改人数，再用人数强行确认候选 |

第一实现使用确定性的有界假设集合（每目标/门最多8个，策略配置冻结），不直接训练一个只见过32条答案的时序网络。似然应来自测量误差和可见性支持；更换成HMM/贝叶斯名称本身不是改进证据。

## 4. 观测与边界的具体实现约束

### 4.1 稳定运动

配对前后相同ID集合：`D={p_after[j]-p_before[j]}`。使用鲁棒二维位移及残差、真实`dt`输出速度，支持数量不足返回缺失。`PortalImageMotion`参考实现已经入库，仅限上身索引0..12。

其`residualSigma`表示支持点之间的残差散布，**不是已校准的定位误差置信区间**。状态估计还需加入由图像分辨率、关键点精度决定的非零传感噪声下限，不能把MAD=0理解成定位绝对正确。

身份换源/换人、倒序时间、过大缺口必须清空未完成点对应。真正的ID交接只能在空间连续、无另一人竞争且一对一关联成立时另行关联，不能简单复制上一owner的travel。

LK保留有效但未满足全部旧门槛的诊断，不把所有原因都压成`flowPoints=0`。每组点保存`sourceFrameSeq`，下一次使用的previous图像必须与它匹配；预算耗尽时统一失效重建，不悄悄跨帧。

### 4.2 前景与参考帧

参考图像只在明确无人/清空的可信区域更新；记录参考帧序号、更新时间和摘要。人体进入时冻结其占用区域的参考，不能因为早启动把人学进背景。允许亮度补偿，但要保留补偿前后诊断。

骨架/人体框是人体前景的种子和空间约束，不是最终轮廓。首选在局部ROI中，将可信人体内部、可信背景、时间传播的前景组成三类种子，求出连通人体前景，再校验纹理/外观连续性；前景质量不足时记录缺失，不用扩大的整个人体框假装轮廓。是否需要轻量分割模型只能由原画面上的消融实验决定，不能现在臆定某个模型必然有效。

每个区域记录`hitPixels/capacityPixels`以及身份归属；均值/质心必须按容量加权。背景变化、阴影、开门等非人体分量不得因落在Portal内就变成人体。

### 4.3 真正的完成锚点

现有Portal是二维透视过渡区。它保留，但需要从原视频确认**与既有T语义一致的边界证据**，不是重标T：

- `VISIBLE_TRANSFER`：能看见同一身体参考部分由源侧经过边界到目的侧；使用固定空间标定和前景对应关系，不用整个人体中心跨地面线替代。
- `OCCLUSION_EDGE`：可见向门内过程之后，人体前景按该门的固定遮挡边缘顺序消失，且未返回源侧；退出为对应的显露及向源侧转移。检测器丢失而像素中人体仍可见不算完成。
- `UNRESOLVED`：现有画面不足以区分走近、门前遮挡与真实穿越时，明确保留不确定。此类样本不从验收中删除；先检查可见区域/机位/标定是否能补足证据，不凭猜测达标。

标定记录建议包含：`gateId`、原Portal多边形、有限穿越边界、源侧/目的侧可见区域、遮挡边缘、模式、标定依据帧及版本。区域是图像语义，除非完成真实平面标定，不称其为米制或三维门后距离。标定按门的固定几何建立，不能每个事件单独调整。

## 5. 状态估计与发布规则

每个“人—门—尝试”维护：源侧支持、穿越中支持、目的侧支持、可见性、方向连续性、测量误差、最后证据时刻和所属身份epoch。

合法解释包括：`SOURCE → APPROACH → TRANSFER → DESTINATION`；`SOURCE → APPROACH → RETURN_SOURCE`；任一中间状态可进入`OCCLUDED/UNKNOWN`并恢复。不得存在无恢复路径的永久RETREAT。

每帧按顺序执行：

1. 校验图像/观测时间和身份；对当前观测做质量评估。
2. 用真实dt传播多个候选；缺测扩大不确定性，不添加虚构证据。
3. 当前帧先做反证：仍在源侧、反向返回、错门归属，均能撤销尚未发布的候选。
4. 有边界完成证据的假设才进入短时确认；默认沿用配置120ms，不能从首次框重叠开始计时。
5. 同时解决空间冲突，发布恰好一次事件；事件时间是本次发布帧时间。
6. 最后更新人数。另存估计发生区间及确认延迟，但不替换响应时间。

相邻门竞争由“是否是同一人体分量、同一运动及互斥的目的区域”判断，不由统一冷却秒数判断。同一人体真实退出A后进入B，即使时间短也不应该被时间锁抹掉。重复抑制挂在已经完成的尝试ID上；新尝试需要新的源侧证据，而不是计时结束自动重发。

## 6. 延迟与算力预算

下表是设计预算，不是已测性能：约90ms分析间隔下，穿越前预观察应已完成，穿越后1～2次有效观测约90～180ms，确认约120ms，采样/计算余量约100～180ms，目标合计约310～480ms。真实设备必须实测分位数，不能把算术预算当保证。

记录至少：`framePtsMs`、`captureElapsedNs`、`measurementDoneElapsedNs`、`publishedElapsedNs`、播放倍率、是否暂停、队列/跳帧原因。视频响应差和墙钟处理耗时分开报告；严格顺序离线解码用于可复现，而真实播放负载用于响应验收，二者都需要。

不新增无界队列、常驻全门高频差分或耗时超过预算还无限等待的处理。局部重任务只作用于活动门，按本帧源图与时间戳关联；降级须显式暴露为低质量，不能输出旧光流作为新测量。

### 当前唯一明确缺失的外部输入

当前已掌握六份完整JSON、地图和32个时间标注，**这些文件不含原视频像素**。因此可完成测量契约、旧模型复现和验收基础，不能从它们重新生成真实人体轮廓/遮挡边缘。需要原`roomxxx`视频的本地路径或可取用源文件；不需要用户重做现有标注，也不需要再运行旧算法导出一份同类摘要。

实现入口读取本地资产清单：视频SHA-256、解码PTS、现有标定、冻结GT。原视频不必提交GitHub；仓库保留摘要和本地路径配置即可。不把需要的像素偷偷替换成JSON推测或虚构的新光流。

## 8. 四层验收不能互相替代

**A 测量契约**：静止/可见性集合变化无伪位移；稠密采样不失明；无帧错配；缺失与零不同；区域容量/坐标意义正确。

**B 已有完整事件集**：32/32、错门0、错向0、漏报0、额外输出0；响应窗[-100,+1000]ms；500ms状态单列。GT摘要固定，文件不完整、标记变化、测量时间错配直接无效或失败。

**C 同视频全链路**：原视频像素重新解码到最终输出；严格顺序与实时负载都测；传感输入变化不能靠只回放旧信号掩盖。每次输出有可追溯的完成证据，不能依赖事件绝对时间。

**D 鲁棒性及盲测**：同一真实动作的所有采样属于同一组；冻结参数后测未参与开发的动作、门口停留、折返、检测器间歇掉人、邻门经过和多人。33/50/75/100/150/200ms采样、合理姿态抖动、3%/10%删帧分别报告最坏结果，不只给中位数。能保持完整可观察证据的正常动作仍需零漏报/误报；移除了唯一完成证据的极端样本应报告不可辨识，不能拿它伪装“已通过”。

完整报告必须注明A/B/C/D各自状态；验收器返回0只能说明它实际检查的契约，不包含尚未测得的墙钟延迟或未来场景保证。未达到500ms目标要明确列出，不以1秒硬线通过宣称速度目标全部完成。
