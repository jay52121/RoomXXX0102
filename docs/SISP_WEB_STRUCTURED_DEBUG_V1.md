# SISP 结构化网页调试与标注台 V1

## 产品范围

**只同步结构化数据，绝不远程传输视频、截图或 Bitmap**。Android 继续负责回顾视频播放、YOLO Pose、Tracker 和房间算法；浏览器通过手机局域网 HTTP 接口显示及控制。

### 网页工具

- **结构化画布**：原摄像头归一化坐标中的房间多边形、门线、白色房间名称、完整 Pose 17 点、骨架、人体框、ID 和分数。支持图层单独显示。
- **播放器**：播放/暂停、从头播放、固定前进/后退 5 秒、前/后一帧、拖动进度、跳到上一/下一事件、下一未绑定事件。
- **按键**：空格=播放/暂停；左/右方向键=固定 -5/+5 秒；逗号/句号=前/后一帧，不因暂停改变 5 秒的含义。
- **人工标记**：当前位置新建“进入/离开”，点击人工事件跳转并选中，在画布或房间按钮上点门直接绑定；支持换门、清除、修改方向、删除和撤销网页最后一次修改。
- **时间线及匹配**：人工事件一轨、算法输出一轨，正确匹配、错门、方向错误、漏判、未到匹配截止点和未观测区间分开标记；展示时间偏差。
- **无匹配跳回（可选）**：播放跨过人工事件的匹配窗口，已有该事件后的实际分析帧，但无**方向+人工房门**有效匹配时，自动跳回该人工事件并暂停。每事件每轮最多触发一次，避免死循环。原有智能匹配暂停/房间切换暂停在该开关期间让路。

### 运行方式

1. Android 保持前台，点击右侧「网页调试」。
2. 将手机与电脑连接同一个局域网，在电脑浏览器打开弹出的地址（默认端口 8765）。
3. 输入手机显示的六位一次性配对码，即可完成全部网页操作。
4. Android 侧再次点击「网页调试」可重新查看连接信息或停止服务。默认关闭；关闭/退出应用后停止服务。

### 实现原则

- 对外只开放固定局域网 HTTP 路由：`/`、`GET /api/state`、`GET /api/frame?ms=...`、`POST /api/command`；数据/命令需要配对码，限内网地址。
- 每个 Pose 分析帧包含 `timeMs/seq/sourceWidth/sourceHeight`，关键点和门区几何都使用原始归一化坐标；浏览器不合成或伪造缺失帧。
- 服务仅保留最近 2500 个分析帧作为缓存；更久的帧需通过回顾视频跳转重新分析。算法事件独立去重，视频或算法切换时清空该轮运行数据。
- **人工真值只有 Android 一份**：所有修改调用现有 `EventMarkerManager`，保存到该视频对应的事件 JSON。不能从 Web 修改 V4 算法结果。
- 手机主线程负责执行远程控制；结构化快照构建/网络收发与 YOLO 推理互不抢锁，不生成 APK 作为网页服务的一部分。
- 第一版仅适用于**回顾视频标注**。实时模式不支持网页控制播放器；原视频像素不在传输范围，所以无法使用网页核对 YOLO 是否错检。

### 验收路径

同一包含 33 个人工事件的视频，在电脑上用键盘前后 5 秒或逐帧，点击事件后绑定房门，修改或撤销，观看双轨匹配，打开跳回开关排查漏判；关闭重进后事件标注仍在。正常网页连接期间不应显著降低 Android Pose 帧率。
